# 📂 Nyaburi · El teu drive de xismes i confidències

**Nyaburi** és una plataforma web dissenyada específicament per al públic escolar i juvenil, que permet gestionar, ordenar i intercanviar "xismes" i secrets d'amor de manera completament anònima i confidencial. L'aplicació simula l'estructura d'un núvol d'emmagatzematge (estil Google Drive) adaptat a les dinàmiques socials dels instituts.

---

## ✨ Característiques principals

*   **📂 Organització tipus Drive:** Crea confidències, organitza-les en carpetes, afegeix estrelles de preferits o gestiona la paperera.
*   **🔄 Sistema d'intercanvis (Fair Play):** Per veure un "xisme" nou, has d'oferir-ne un de teu a canvi. El panell d'intercanvis monitoritza l'estat de cada acord.
*   **🪙 Missions i Buris:** Completa missions dins la plataforma per guanyar *Buris*, la moneda interna del joc (sense valor comercial).
*   **🔒 Seguretat i Anonimat:** Dissenyat per garantir la privacitat i la confidencialitat de totes les històries i usuaris.

---

## 🚀 Com funciona?

1.  **Crea i Ordena:** Desa els secrets de la teva escola i classifica'ls per carpetes.
2.  **Proposa un Tracte:** Selecciona un dels teus xismes i proposa un intercanvi a un altre membre.
3.  **Descobreix:** Un cop acceptat el tracte, es desbloqueja el xisme nou a la teva unitat.
