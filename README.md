# nyaburi
Plataforma web per a escoles dedicada a compartir de forma anònima i segura els secrets d'amor, "crushes" i el safareig de l'institut. El projecte busca crear un espai d'entreteniment i complicitat entre alumnes, gestionant les interaccions socials del dia. Desenvolupada amb un disseny interactiu, modern, intuïtiu i totalment adaptat a mòbils.
